# PREDICTING HEART DISEASE

A complete Machine Learning and Data Analysis project using Python and Power BI — analyzing health data from 180 patients to identify factors associated with heart disease and build classification models for prediction.

🛠️ Tools & Technologies

- Programming: Python
- Libraries: Pandas, NumPy, Matplotlib, Seaborn, Scikit-learn
- Machine Learning: Logistic Regression, KNN, Decision Tree, Random Forest
- Data Visualization: Matplotlib, Seaborn, Power BI
- Platform: Google Colab

📊 Key Insights

- 80 out of 180 patients (44%) had heart disease.
- Exercise-induced angina, number of major vessels, chest pain type, oldpeak, and maximum heart rate showed meaningful relationships with heart disease.
- Sex also showed an association with heart disease in the analyzed dataset.
- Patients with heart disease showed a higher average number of affected major vessels.
- Serum cholesterol showed only a slight difference between patients with and without heart disease.
- The analysis indicates that multiple features together are useful for heart disease prediction rather than relying on a single variable.

📁 Project Structure

- `data/` — Patient health dataset
- `Machine Learning/` — Python notebook containing data analysis and machine learning models
- `PowerBI/` — Interactive Power BI dashboard and screenshots
- `README.md` — Project documentation

🔍 What This Project Covers

1. Loaded and merged patient health data using Pandas
2. Checked missing values and duplicate records
3. Performed exploratory data analysis (EDA)
4. Analyzed relationships between health features and heart disease
5. Created visualizations using Matplotlib and Seaborn
6. Split the dataset into training and testing data
7. Built Logistic Regression, KNN, Decision Tree, and Random Forest models
8. Evaluated models using accuracy, recall, classification reports, and confusion matrices
9. Implemented individual patient heart disease prediction
10. Created an interactive Power BI dashboard for data visualization

🤖 Model Analysis

Four classification models were implemented and compared:

- Logistic Regression
- K-Nearest Neighbors (KNN)
- Decision Tree
- Random Forest

The models were evaluated using accuracy and recall scores on the test dataset.

📈 Power BI Dashboard

An interactive Power BI dashboard was created to visualize patient data, heart disease distribution, and important health-related factors.

🎯 Conclusion

This project demonstrates how Python, Machine Learning, and Power BI can be combined to analyze healthcare data, identify important patterns, build predictive classification models, and present insights through interactive visualizations.
